# Style guide (scratchpad)

Running notes toward a voice and tone guide. Not published.

## Punctuation

- **Dashes.** Write em dashes as `---` (renders as —), spaced: `word --- word`. A double hyphen `--` renders as an en dash (–), which is for ranges, not breaks in a sentence. Common slip of mine.
- **Throwaway asides.** All lowercase, no closing punctuation, in parentheses: `(spoiler: this still took just an afternoon, maybe just a longer one)`. If an aside runs to more than one sentence, use normal capitalization inside it.

## Word choice

- Name alternatives with "or", not a slash: "Hugo or 11ty", not "Hugo/11ty".
- "markdown" is always lowercase.
- Prefer "I have" over "I've got". Common slip of mine.
- Say "AI", not a specific tool name, when describing how work was done.

## Voice

- **Deliberate** repetition for emphasis is fine ("wasn't mine, not really"). Don't edit it out, but question it.
